# bratLyrics

<p>This is a web app to create brat-style lyrics videos with transparency to overlay on top of videos. The video format is natively supported by Adobe Premiere Pro.</p> 


## Usage
<ul>
  <li>1. Download synced lyrics (.lrc) file from any website</li>
  <li>2. Run the server.py file using the command line, and the website should open in a specific port.</li>
  <li>3. Upload the .lrc file to the input field and it should create a video timeline with the lyrics and the text should look brat-style</li>
</ul>
